# Attribution and release review

This repository accompanies *cWB-space: A time-frequency transient-search pipeline for LISA*, Shubhanshu Tiwari, Yumeng Xu, and Giovanni A. Prodi, arXiv:2609.12986v1.

A project software license and a data license have not yet been selected by the authors. No new license grant is implied. The paper's arXiv license does not automatically license all software or input data.

Dependencies are installed separately, not vendored. The inspected WDM-wavelet 0.3.0 distribution carries GPLv3 terms; NumPy, SciPy, pandas, Matplotlib and other dependencies retain their respective licenses. Review compatibility before choosing a software license. LISA Data Challenge inputs retain their original attribution and redistribution conditions; included Sangria products are derived candidate lists and waveform comparison samples, not the full challenge release.
